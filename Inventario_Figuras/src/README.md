# PROYECTO INVENTARIO_FIGURAS
Se trata de una aplicación para guardar en base de datos a partir de un inventario dado, la información de los productos. Este proyecto incluye código fuente estructurado y documentación.

## TECNOLOGÍAS UTILIZADAS
* **Java** (Programación Orientada a Objetos)
* **Eclipse IDE** (Entorno de desarrollo)
* **Git & GitHub** (Control de versiones)
* **Javadoc** (Documentación del código)
  
### CARACTERÍSTICAS DEL PROYECTO 
* **Código limpio:** Estructurado siguiendo las buenas prácticas de desarrollo en Java.(Versión Junior limpia y legible).
* **Documentación completa:** Comentarios estructurados y procesados de los métodos utilizados, a través de la herramienta Javadoc.
